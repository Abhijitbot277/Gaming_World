# Rift Runner — Roblox prototype

A multiplayer survival prototype: collect glowing coins, move between floating islands, and survive the collapsing-rift round.

## Included
- Server-generated floating island arena
- Coin pickups and leaderboard stats (Coins, Survivals)
- Round countdown and island-collapse timer
- Roblox-native Luau scripts

## Open and publish
1. Install Roblox Studio.
2. Install the Rojo CLI, or use the Rojo Studio plugin.
3. From this folder, run `rojo serve` and connect the Studio plugin, or build a place file with `rojo build -o RiftRunner.rbxlx`.
4. Test with **Test → Start** and multiple players.
5. In Studio, choose **File → Publish to Roblox**.

This is a starter prototype, not a finished commercial release. Test and tune map layout, round logic, mobile controls, UI, and persistence before publishing.
